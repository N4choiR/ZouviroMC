# MiniCode Web

Lightweight Online Code Minification and Formatting Toolkit.

## Features

- HTML Minifier
- CSS Minifier
- JavaScript Minifier
- JSON Minifier
- XML Minifier
- Code Beautifier
- Dark / Light Theme
- Browser / Server Processing

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- CodeMirror 6
- Node.js
- Fastify

Status: Under Development.
